# Newsroom: the news desk as its own product at /newsroom

Date: 2026-09-27 · Approved in chat (answers: open sign-up, `/newsroom`, all tools, landing page).

## Why
The news desk is for TV channels, not ordinary shops. It moves out of the
shop app (`/app`) to its own address with its own entry page, sign-in copy,
header and tab bar. The shop app goes back to how it was before 2026-09-26.

## Decisions
- **One account, one kind.** The first surface a new account opens claims it:
  `/newsroom…` makes it a channel (`Tenant.kind = NEWS`), `/app…` a shop
  (`MERCHANT`). `Tenant.kindChosen` now means "claimed". No chooser any more.
- A channel opening `/app` is sent to `/newsroom/news`. A shop opening
  `/newsroom/…` (signed in) sees a notice: this email belongs to a shop; sign
  up for the newsroom with another email (with a sign-out button).
- Claiming NEWS also creates the desk settings and the GDELT source (what
  `setTenantKindAction` did) and renames the default workspace name
  `دووکانەکەم` to `کەناڵەکەم`.
- Newsroom tools = all of the shop app's tools plus the desk: هەواڵ · کۆمێنت ·
  نامە · بڵاوکردنەوە · ئامار, Settings in the header. The shared pages are
  re-exported under `/newsroom/(desk)/…`; they already work on "the signed-in
  user's workspace", and one account has one workspace.
- Links inside shared screens must stay inside the product the user is in:
  server code uses `baseFor(ws.kind)`, client code `useBase()` (from the URL).
- Everything below the screens is unchanged: ingest, DeepSeek, cards, rules,
  quotas, publishing, TikTok photos.

## Tasks

### 1. Kind claiming and base paths (`src/app/app/data.ts`, new `src/app/app/use-base.ts`)
- `export type Kind = "MERCHANT" | "NEWS";`
- `export function baseFor(kind: Kind): "/app" | "/newsroom"`.
- `export async function claimKind(ws: Workspace, kind: Kind): Promise<Workspace>` —
  when `ws.kindChosen` is false: update `kind` and `kindChosen: true` (and for
  NEWS: upsert `NewsSettings`, upsert the `gdelt` `NewsSource` by
  `tenantId_catalogId`, and rename the tenant if its name is `دووکانەکەم`);
  return the updated workspace. When already claimed, return it unchanged.
  Wrap the database work in try/catch and return `ws` unchanged on failure.
- `use-base.ts` ("use client"): `export function useBase(): "/app" | "/newsroom"`
  from `usePathname()` (`/newsroom` prefix → "/newsroom", else "/app").

### 2. Shop app back to before (`src/app/app/…`)
- `layout.tsx`: after loading the workspace, `if (!ws.kindChosen) ws = await claimKind(ws, "MERCHANT")`;
  `if (ws.kind === "NEWS") redirect("/newsroom/news")`.
- `page.tsx` (Today): remove the chooser and the NEWS redirect lines and the `KindChooser` import.
- Delete `kind-chooser.tsx`. Remove `setTenantKindAction` from `actions.ts` (its logic now lives in `claimKind`).
- `nav.tsx`: `Tabs({ kind })` builds the shared tabs from `baseFor(kind)`:
  MERCHANT → ئەمڕۆ `/app` + کۆمێنت/نامە/بڵاوکردنەوە/ئامار under `/app`;
  NEWS → هەواڵ `/newsroom/news` + the same four under `/newsroom`.
  The active-tab logic must work for both bases.
- `settings/settings-client.tsx`: remove the kind-switch block ("جۆری هەژمار") and
  its imports; connect links use `next=${base}/settings`; sign-out goes to
  `/login?next=${base}`. Keep the news settings section (shown for NEWS).
- Every other hard-coded `/app…` link in shared screens (`comments-client.tsx`,
  `messages-client.tsx`, `publish/publish-client.tsx`, `publish/page.tsx`,
  `insights/page.tsx`, `settings/password-card.tsx`, `settings/news-settings.tsx`,
  and any other file `grep -rn '"/app\|`/app' src/app/app` finds) uses the base:
  `useBase()` in client components, `baseFor(ws.kind)` in server components.
